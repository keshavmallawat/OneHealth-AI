# OneHealth AI - Unified Digital Health Record Platform

OneHealth AI is a comprehensive, AI-powered healthcare platform designed to provide a unified digital health record experience. It offers robust authentication, role-based access control, secure health record management, and an AI-driven chat interface for enhanced patient care and clinical support.

## Structure
- `frontend/`: React-based web application frontend
- `backend/`: Node.js API services with robust RBAC and file storage
- `ai-service/`: AI and ML models for predictive insights and chat capabilities
- `infra/`: Infrastructure and deployment configuration (Docker, AWS)
- `docs/`: Project documentation
